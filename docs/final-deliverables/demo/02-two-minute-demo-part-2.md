# Two-Minute Demo Script — Part 2: Attendance and Close

**Target duration:** 1:00–2:00. Use only features that have been verified in the exact release build.

| Time | What to show | Narration |
|---|---|---|
| 1:00–1:20 | Demonstrate marking one attendance record using the actual route/screen and a synthetic student/course/date. | “We record attendance for the selected student and course. The SRS defines Present, Absent, Late and Excused as the required attendance statuses.” |
| 1:20–1:35 | Retrieve the saved record or class register using the implemented flow. | “We retrieve the saved attendance and confirm that the stored value matches the entry.” |
| 1:35–1:50 | Demonstrate the attendance percentage/summary feature only if it is present and verified. | “The summary is checked against the underlying test records to confirm that the calculation is correct.” |
| 1:50–2:00 | Show the test report or known-limitations summary. | “This demonstration covers the features verified in this build. Any remaining SRS requirements are documented as not delivered or not verified rather than presented as completed.” |

## Presenter checklist

- [ ] Build SHA and environment recorded.

- [ ] IDs used in later steps match the records created earlier.
